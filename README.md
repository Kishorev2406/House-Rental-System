House Rental System

House Rental System is a web-based application developed to simplify the process of searching, listing, and managing rental properties. The system allows property owners to add and manage house details, while tenants can view available properties, check rental information, and find suitable houses based on their requirements. It reduces the manual effort involved in property searching and provides an organized platform for managing rental information.

Key Features:

Property listing and management
House details including location, rent, and availability
Tenant-friendly property search
Property owner management
Simple and user-friendly interface
Centralized rental property information
